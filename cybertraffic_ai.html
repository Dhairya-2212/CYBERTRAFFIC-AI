Architecture

Five formulas turn raw sensor numbers into a green time and a speed check. Each one is explained in plain words, followed by the Python that implements it.

The maths, step by step

Mathematical Foundations & Fuzzy Logic Engine
Formal Math
1

Triangular membership function

Turns a raw number, such as 20 cars, into a degree from 0 to 1 for a label like Low, Medium or High.

μ(x; a, b, c) = max(0, min((x - a)/(b - a), (c - x)/(c - b)))
2

Mamdani rule evaluation & firing strength

Each rule is as strong as its weaker condition: queue or wait, whichever matches less.

α_i = min(μ_Queue(q), μ_Wait(w)) for rule i ∈ {1..9}
3

Aggregation operator (MAX)

Combines every rule's result into one shape by keeping the highest value at each point.

μ_Agg(z) = max_{i} [min(α_i, μ_{Duration, i}(z))]
4

Center of Gravity (centroid) defuzzification

Finds the balance point of that shape. That point is the green time in seconds.

Z* = [∫ z · μ_Agg(z) dz] / [∫ μ_Agg(z) dz]
5

Optical flow speed calculation

Converts how far a vehicle moved between video frames into km/h. Above the limit, it is flagged.

v = (Δd_px / Δt) · (metres_per_px) · 3.6 [km/h]
If v > 80.0 km/h: Trigger Automated Violation Challan

Python source implementation

Pure Python / Skfuzzy 
import numpy as np

def trimf(x, abc):
    a, b, c = abc
    y = np.zeros_like(x, dtype=float)
    if a != b:
        i1 = (a <= x) & (x <= b)
        y[i1] = (x[i1] - a) / (b - a)
    if b != c:
        i2 = (b <= x) & (x <= c)
        y[i2] = (c - x[i2]) / (c - b)
    return np.clip(y, 0.0, 1.0)

def defuzz_centroid(x, mfx):
    s = np.sum(mfx)
    return np.sum(x * mfx) / s if s != 0 else np.mean(x)

class TrafficFuzzyController:
    def __init__(self):
        self.u_dur = np.arange(10, 91, 0.5)
        self.mf_dur = {
            'short': [10.0, 20.0, 30.0],
            'medium': [25.0, 42.5, 60.0],
            'long': [50.0, 70.0, 90.0]
        }
        self.mf_queue = {
            'low': [0.0, 0.0, 15.0],
            'medium': [10.0, 22.5, 35.0],
            'high': [30.0, 50.0, 50.0]
        }
        self.mf_wait = {
            'short': [0.0, 0.0, 3.0],
            'medium': [2.0, 4.5, 7.0],
            'long': [5.0, 10.0, 10.0]
        }
        self.rules = [
            ('low', 'short', 'short'),
            ('low', 'medium', 'short'),
            ('low', 'long', 'medium'),
            ('medium', 'short', 'medium'),
            ('medium', 'medium', 'medium'),
            ('medium', 'long', 'long'),
            ('high', 'short', 'long'),
            ('high', 'medium', 'long'),
            ('high', 'long', 'long')
        ]

    def compute(self, queue, wait, emergency=False):
        if emergency:
            return 90.0  # Emergency Vehicle Priority (EVP) override

        # Fuzzify antecedents
        mu_q = {k: trimf(np.array([queue]), v)[0] for k, v in self.mf_queue.items()}
        mu_w = {k: trimf(np.array([wait]), v)[0] for k, v in self.mf_wait.items()}

        # Evaluate 9 Mamdani rules (MIN implication)
        cuts = {'short': 0.0, 'medium': 0.0, 'long': 0.0}
        for q_term, w_term, out_term in self.rules:
            alpha = min(mu_q[q_term], mu_w[w_term])
            cuts[out_term] = max(cuts[out_term], alpha)

        # MAX aggregation
        mfx = np.zeros_like(self.u_dur)
        for term, cut in cuts.items():
            mf = trimf(self.u_dur, self.mf_dur[term])
            mfx = np.maximum(mfx, np.minimum(cut, mf))

        # Centroid defuzzification -> crisp green time in seconds
        return defuzz_centroid(self.u_dur, mfx)
